# frontend-

A simple frontend project containing a Google Form-style HTML page.

## Files

- `index.html` — A styled feedback form with name, email, course selection, satisfaction rating, checkbox options, and a feedback textarea.

## Usage

1. Open `index.html` in your browser.
2. Fill in the form fields.
3. Submit the form (currently a static HTML form with no backend).

## Form Fields

The feedback form includes the following fields:

- **Name**: Optional text input for the user's name.
- **Email**: Required email input.
- **Course**: Dropdown selection for the attended course (HTML & CSS, JavaScript, React, Vue).
- **Satisfaction**: Radio buttons for satisfaction level (Very satisfied, Satisfied, Neutral, Dissatisfied).
- **Liked Most**: Checkboxes for what the user liked (Examples, Exercises, Pace, Presentation).
- **Additional Feedback**: Textarea for open-ended comments.

## Notes

- This page is designed to look like a Google Form UI.
- To collect responses, add a backend or connect the form to a submission service.
